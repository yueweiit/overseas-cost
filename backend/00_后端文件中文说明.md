# 后端文件中文说明

本文档用于说明 `backend` 目录下第一版 Frappe 后端骨架的中文名、用途和修改建议。

## 1. 顶层文件

| 路径 | 中文名 | 用途 | 是否建议直接修改 |
| --- | --- | --- | --- |
| `README_后端目录规划与用途.md` | 后端目录规划说明 | 说明 `backend` 目录整体要放什么 | 是 |
| `00_后端文件中文说明.md` | 后端文件总说明 | 说明当前所有后端骨架文件的中文名和用途 | 是 |
| `overseas_costing/` | Frappe自定义应用目录 | 海外采购综合成本核算模块后端正式代码主体 | 是 |

## 2. 自定义应用目录

| 路径 | 中文名 | 用途 |
| --- | --- | --- |
| `overseas_costing/README_应用目录说明.md` | 应用目录说明 | 应用根目录总说明 |
| `overseas_costing/README.md` | 应用英文入口说明 | 便于后续标准化接入 Frappe / Git |
| `overseas_costing/setup.py` | Python安装配置 | 作为 Frappe 自定义 app 的安装入口 |
| `overseas_costing/MANIFEST.in` | 打包清单 | 控制安装包中包含哪些非 Python 文件 |
| `overseas_costing/requirements.txt` | Python依赖清单 | 记录后端额外依赖 |
| `overseas_costing/modules.txt` | Frappe模块声明 | 声明本 app 的模块名 |
| `overseas_costing/patches.txt` | 补丁登记文件 | 记录后续数据库/数据补丁入口 |
| `overseas_costing/license.txt` | 许可证说明 | 当前先放占位说明 |

## 3. Python包主目录

| 路径 | 中文名 | 用途 |
| --- | --- | --- |
| `overseas_costing/overseas_costing/__init__.py` | 应用包入口 | 定义版本号 |
| `overseas_costing/overseas_costing/hooks.py` | Frappe钩子文件 | 配置 app 元信息、安装钩子、文档类型入口 |
| `overseas_costing/overseas_costing/install.py` | 安装初始化文件 | 后续安装 app 时执行初始化逻辑 |
| `overseas_costing/overseas_costing/constants.py` | 常量定义文件 | 放状态枚举、版本类型、运输方式等常量 |

## 4. 子目录说明

| 路径 | 中文名 | 用途 |
| --- | --- | --- |
| `config/` | 配置目录 | 放桌面模块和 Frappe 模块展示配置 |
| `api/` | 接口目录 | 放前端可调用的 whitelisted API |
| `services/` | 服务目录 | 放导入、重算、版本、审计等业务服务 |
| `utils/` | 工具目录 | 放字段映射、汇率处理、参数校验工具 |
| `doctype/` | DocType目录 | 放批次、版本、明细、规则、附件、日志的 DocType 骨架 |
| `page/` | 页面目录 | 放 Frappe 页面后端入口文件 |
| `scripts/` | 辅助脚本目录 | 放一次性导入脚本、批次重算脚本骨架 |
| `tests/` | 测试目录 | 放后续单元测试和工具测试 |

## 5. 当前开发顺序建议

1. 先看 `docs/01_PRD...`
2. 再看 `backend/overseas_costing/overseas_costing/constants.py`
3. 再看 `backend/overseas_costing/overseas_costing/doctype/`
4. 再看 `backend/overseas_costing/overseas_costing/api/`
5. 再写 `services/`

## 6. 当前阶段说明

这一版还属于“第一版后端骨架”，重点是：

1. 把目录标准化
2. 把 API 入口占住
3. 把核心 DocType 骨架搭起来
4. 把中文用途说明补齐

还不等于：

1. 已接 ERP
2. 已接数据库
3. 已完成导入
4. 已完成重算
