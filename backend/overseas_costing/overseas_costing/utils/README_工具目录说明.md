# 工具目录说明

适用目录：`overseas_costing/utils`

## 文件清单

| 文件 | 中文名 | 用途 |
| --- | --- | --- |
| `field_mapper.py` | 字段映射工具 | 做 OA / Excel 到系统字段的映射收口 |
| `currency.py` | 汇率工具 | 做汇率换算和金额四舍五入 |
| `dingtalk.py` | 钉钉跳转工具 | 生成审批实例的移动端 / PC 钉钉跳转链接 |
| `validators.py` | 参数校验工具 | 做基础字段判空、枚举校验、数值校验 |

## 当前约定

1. 可复用的纯函数尽量放这里
2. 不要把业务主流程写在 utils
