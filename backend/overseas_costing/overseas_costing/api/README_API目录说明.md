# API 目录说明

适用目录：`overseas_costing/api`

## 文件清单

| 文件 | 中文名 | 用途 |
| --- | --- | --- |
| `batch.py` | 批次查询接口 | 查批次列表、批次详情、明细、版本列表、钉钉原单跳转 |
| `category.py` | 商品品类归类接口 | 返回商品品类归类预览，后续接 AI 分类与人工确认 |
| `import_api.py` | 导入接口 | 导入 Excel / OA 数据、上传附件、完税凭证 PDF 预览解析、解析快照保存与记录摘要查询 |
| `calculate.py` | 编辑重算接口 | 编辑字段、批量编辑、重算、版本切换 |
| `writeback.py` | 回写接口 | 检查回写条件、执行回写 |

## 当前约定

1. API 层只做参数入口和结果封装
2. 核心业务放到 `services/`
3. 需要 whitelisted 的方法统一从这里暴露
