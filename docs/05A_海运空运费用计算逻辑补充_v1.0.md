# 海运/空运费用计算逻辑说明

来源文件：`C:\Users\lin\OneDrive\Desktop\freight-calculation.html`

整理日期：2026-07-03

## 1. 文档目的

本文记录 `freight-calculation.html` 中海运、空运页面背后的计算逻辑，供后续对接“海外采购综合成本核算模块”时复用、校验或改造成规则引擎。

需要注意：该 HTML 是单票/单项费用计算器，不是完整的多采购单、多供应商、多 SKU 批次成本核算模型。它可以作为费用计算口径参考，但不能直接覆盖当前海外采购综合成本核算的一期完整需求。

## 2. 汇率逻辑

页面统一将费用折算为人民币口径计算。

默认备用汇率：

| 币种 | 默认折算 |
| --- | --- |
| USD -> CNY | 1 USD = 7.25 CNY |
| MXN -> CNY | 1 MXN = 0.42 CNY |

页面加载时会调用 `https://open.er-api.com/v6/latest/USD` 获取实时汇率。

汇率换算规则：

```text
USD_TO_CNY = data.rates.CNY
MXN_TO_CNY = (1 / data.rates.MXN) * USD_TO_CNY
```

如果接口失败，则回退到默认备用汇率，并提示用户当前使用备用汇率。

## 3. 通用申报货值折算

空运、海运都支持申报货值币种选择：人民币 CNY、美元 USD、墨西哥比索 MXN。

统一折算公式：

```text
如果币种 = CNY：
申报货值人民币 = 申报货值

如果币种 = USD：
申报货值人民币 = 申报货值 * USD_TO_CNY

如果币种 = MXN：
申报货值人民币 = 申报货值 * MXN_TO_CNY
```

折算后的 `申报货值人民币` 会作为后续 CIF、关税、增值税计算基础。

## 4. 空运计算逻辑

### 4.1 空运输入字段

| 字段 | 说明 | 是否参与计算 |
| --- | --- | --- |
| 申报名称 | 展示字段 | 否 |
| 发货数量 | 用于平均每套成本 | 是 |
| 重量 kg | 展示字段 | 否 |
| 体积 m3 | 展示字段 | 否 |
| 空运费用 CNY | 直接作为空运费 | 是 |
| 申报货值币种 | CNY / USD / MXN | 是 |
| 申报货值金额 | 按币种折算为人民币 | 是 |
| 关税率 % | 计算关税 | 是 |
| 增值税率 % | 默认 16% | 是 |
| 清关杂费 MXN | 折算为人民币 | 是 |
| 拖车费 CNY | 直接计入清关费用 | 是 |

### 4.2 空运核心公式

```text
空运费 = 输入的空运费用 CNY

CIF价值 = 空运费 + 申报货值人民币

关税费用 = CIF价值 * 关税率 / 100

DTA费用 = (CIF价值 + 关税费用) * 0.0008

增值税费用 = (CIF价值 + 关税费用) * 增值税率 / 100

清关杂费人民币 = 清关杂费MXN * MXN_TO_CNY

清关总费用 = 清关杂费人民币 + DTA费用 + 拖车费CNY + 增值税费用

总成本 = 空运费 + 清关总费用

平均每套成本 = 总成本 / 发货数量
```

### 4.3 空运输出

页面展示两部分：

| 输出区域 | 字段 |
| --- | --- |
| 费用支出明细 | 空运费、申报货值、CIF 价值、关税率、增值税率、关税费用、增值税费用、清关杂费、DTA 费用、拖车费、清关费用 |
| 费用汇总 | 空运费汇总及平均每套、清关费用汇总及平均每套、总价及平均每套 |

空运导出 Excel 时会生成 3 个 Sheet：

| Sheet | 内容 |
| --- | --- |
| 基础数据 | 输入字段、申报货值折算、费率、其他费用、汇率信息 |
| 费用支出明细 | 各费用明细及清关总费用 |
| 费用汇总 | 空运费、清关费用、总价的汇总和平均每套成本 |

## 5. 海运计算逻辑

### 5.1 海运输入字段

| 字段 | 说明 | 是否参与计算 |
| --- | --- | --- |
| 申报名称 | 展示字段 | 否 |
| 发货数量 | 仅记录/导出，当前公式未用于单价 | 否 |
| 重量 kg | 当前货物重量，用于分摊整柜费用 | 是 |
| 整柜重量 kg | 整柜总重量，用于计算分摊比例 | 是 |
| 体积 m3 | 展示/导出字段，当前公式未使用 | 否 |
| 海运费 CNY | 作为整柜海运费基数 | 是 |
| 申报货值币种 | CNY / USD / MXN | 是 |
| 申报货值金额 | 按币种折算为人民币 | 是 |
| 关税率 % | 计算关税 | 是 |
| 增值税率 % | 默认 16% | 是 |
| 清关杂费 MXN | 按重量比例分摊后折算人民币 | 是 |
| 拖车费 MXN | 按重量比例分摊后折算人民币 | 是 |

### 5.2 海运分摊比例

当前 HTML 海运只使用重量比例分摊费用。

```text
重量分摊比例 = 当前货物重量 / 整柜重量
```

如果用户未填写重量或整柜重量，代码会默认使用 1，避免除以 0。

### 5.3 海运核心公式

```text
海运费分摊额 = 整柜海运费CNY * (当前货物重量 / 整柜重量)

CIF价值 = 海运费分摊额 + 申报货值人民币

关税费用 = CIF价值 * 关税率 / 100

DTA费用 = (CIF价值 + 关税费用) * 0.0008

增值税费用 = (CIF价值 + 关税费用) * 增值税率 / 100

清关杂费人民币 = 清关杂费MXN * (当前货物重量 / 整柜重量) * MXN_TO_CNY

拖车费人民币 = 拖车费MXN * (当前货物重量 / 整柜重量) * MXN_TO_CNY

清关总费用 = 清关杂费人民币 + DTA费用 + 拖车费人民币 + 增值税费用

总成本 = 海运费分摊额 + 清关总费用

平均每公斤成本 = 总成本 / 当前货物重量
```

## 6. 空运与海运差异总结

| 对比项 | 空运 | 海运 |
| --- | --- | --- |
| 运费来源 | 输入空运费，直接使用 | 输入整柜海运费，再按重量比例分摊 |
| 杂费分摊 | 清关杂费不分摊，直接按 MXN 折 CNY | 清关杂费按重量比例分摊后折 CNY |
| 拖车费币种 | 人民币 CNY | 墨西哥比索 MXN |
| 拖车费处理 | 直接计入清关费用 | 按重量比例分摊后折 CNY |
| 输出单价 | 平均每套成本 | 平均每公斤成本 |
| 体积字段 | 只记录，不参与计算 | 只记录，不参与计算 |
| 重量字段 | 只记录，不参与计算 | 参与整柜费用分摊 |

## 7. 与海外采购综合成本核算模块的衔接建议

当前 HTML 的逻辑可以沉淀为“运输方式费用计算模板”，但接入综合成本核算模块时建议做以下改造：

1. 将 `海运/空运` 抽象为运输方式枚举，当前一期只启用海运，空运入口保留。
2. 将汇率作为成本版本字段保存，避免后续重新打开批次时因实时汇率变化导致历史成本变动。
3. 将 DTA 费率 `0.0008` 配置化，不建议硬编码。
4. 将增值税、关税、DTA 的计税口径做成可确认规则，因为当前 HTML 使用 `CIF + 关税` 作为 DTA 和增值税的基础。
5. 海运分摊规则目前只有重量比例，综合成本模块还需要支持按货值、体积重量、实际重量等规则切换。
6. 当前公式是单票/单项费用计算，综合成本模块需要扩展到批次、报关单、运单、采购单、供应商、SKU 多层级。
7. 当前空运的重量和体积未参与计算，如果后续做空运，需要确认是否使用计费重量：`max(实际重量, 体积重量)`。
8. 当前海运的发货数量未参与成本单价，若要输出 SKU 综合单价，需要按物料数量或库存单位继续分摊。

## 8. 当前 HTML 逻辑中的待确认点

| 待确认点 | 说明 |
| --- | --- |
| 海运分摊是否只按重量 | 当前 HTML 只按重量分摊整柜海运费、清关杂费、拖车费；但业务需求中还提到按货值或体积重量分摊。 |
| 增值税计税基数是否包含 DTA | 当前公式为 `(CIF + 关税) * 增值税率`，未把 DTA 纳入增值税基数。需财务确认。 |
| DTA 费率是否固定 0.08% | 当前代码固定 `0.0008`，需确认是否所有品类/批次都适用。 |
| 空运是否需要计费重量 | 当前空运重量、体积只展示，不参与运费计算。 |
| 海运是否需要按体积或体积重量 | 当前海运体积只展示，不参与分摊。 |
| 申报货值是否等同采购货值 | 当前 HTML 用申报货值计算 CIF；综合成本文件中可能同时存在采购货值、报关申报货值，需要区分。 |

## 10. 结论

`freight-calculation.html` 的核心价值是提供了一个可运行的运输费用计算样例：统一汇率折算、CIF、关税、DTA、增值税、清关杂费、拖车费、总成本和单位成本。

但它目前更像“单项运输费用计算器”，不是“批次级 SKU 综合成本核算引擎”。后续接入海外采购综合成本核算模块时，应将其公式拆成可配置规则，并与批次、报关单、运单、SKU 明细表联动。
