# 开发阅读顺序

适用对象：模块后续开发人自己使用，不面向经理汇报。

当前最终口径：
1. 页面采用单页平铺整表展示。
2. 字段严格按 Excel 原列顺序展示。
3. 不做“关联单据 / 费用池 / 分摊规则 / SKU 明细”等多模块重规划。
4. 所有开发以 `01_PRD_海外采购综合成本核算模块_海运一期_v1.0.md` 为准。

## 建议先看

1. `01_PRD_海外采购综合成本核算模块_海运一期_v1.0.md`
   先确认一期边界、页面形态、海运优先、Excel 列顺序直展示、暂估/实际、人工修改留痕这些核心要求。

2. `05_核算系统计算逻辑与字段分析_v1.0.md`
   先把 Excel 79-121 行的真实核算逻辑吃透，尤其是货值分摊、重量分摊、综合成本形成方式。

3. `04_API与重算流程设计_海外采购综合成本核算模块_v1.0.md`
   看清楚导入、保存、重算、版本切换、回写这些核心接口和流程怎么落。

## 然后再看

4. `02_Frappe架构设计_海外采购综合成本核算模块_v1.0.md`
   明确这个模块在 Frappe / ERP 里的落位方式，知道后端服务、计算服务、导入服务、日志服务怎么拆。

5. `03_DocType与MariaDB设计_海外采购综合成本核算模块_v1.0.md`
   开始建表、建 DocType、梳理主从结构前看这份。

## 作为补充参考

6. `05A_海运空运费用计算逻辑补充_v1.0.md`
   这是从 `freight-calculation.html` 提炼出来的单票海运/空运费用逻辑，适合作为后续扩展空运时参考。

7. `06_Demo原型说明_海外采购综合成本核算模块_v1.0.md`
   主要用于对照当前 Demo 已实现什么、哪些只是前端演示、哪些后面要进 Frappe 正式化。

8. `07_OA国际物流单_系统字段映射表_v1.0.md`
   这份用于梳理钉钉 OA 国际物流审批单能直接带来哪些字段、哪些字段需要转换、哪些成本字段仍需靠采购/报关/凭证补齐。


## 真正开工时的建议顺序

1. 先定数据模型：批次、单据、SKU 明细、费用项、成本版本、修改记录。
2. 再定导入链路：Excel 导入、字段映射、数据落库、异常提示。
3. 再做计算链路：分摊规则、汇率快照、暂估/实际、整票重算。
4. 再做页面：按 Excel 列顺序直展示，支持筛选、编辑、保存、重算。
5. 最后补回写 ERP、权限、操作日志、差异追踪。
