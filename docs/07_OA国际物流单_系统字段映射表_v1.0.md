# OA 国际物流单 -> 系统字段映射表 V1.0

更新时间：2026-07-08

## 1. 文档目标

本文件用于说明：

1. 钉钉 OA 导出的 `国际物流 Logística Internacional` 表，哪些字段可以直接进入当前成本核算系统。
2. 哪些字段需要经过归一化、拆分、解析后才能进入系统。
3. 哪些成本核算关键字段在 OA 单中并不存在，后续必须依赖采购、报关、凭证识别或人工补录。

## 2. 对比口径

### 2.1 OA 来源文件

- 文件：`C:\Users\lin\OneDrive\Desktop\国际物流Logística+Internacional-20260708110155.xlsx`
- 特征：每个 sheet 前两行是表头，其中：
  - 第 1 行是分组名
  - 第 2 行是实际业务字段名
- 本文映射以第 2 行字段名为准

### 2.2 当前系统字段口径

- 系统主表范围：`A ~ BE`
- 当前开发口径：单页平铺整表展示
- 本次已确认调整：
  - `A列` 从“备注（计算分摊比列、物品编码和汇率换算）”改为 `物料编码`
  - Demo 阶段如原 Excel A 列存在备注/换算说明，会并入 `物料编码` 列一并展示，避免原数据丢失
  - Frappe 正式后端中，`material_code` 作为正式物料字段保留，历史 A 列备注/换算说明单独落 `source_remark`

### 2.3 分类说明

- `可直接映射`：语义一致，基本不需要加工即可落表
- `需转换`：能提供价值，但需要归一化、拆分、规则判断或文本解析
- `缺失待补`：系统核算需要，但 OA 国际物流单没有，必须从其他来源补齐

## 8. 开发结论

当前最合理的落地方式不是“只靠 OA 国际物流单直接生成最终成本表”，而是：

1. 先用 `OA 国际物流单` 生成批次头、物流头、基础物料行。
2. 再用 `ERP采购数据` 补单价、数量校验、货值。
3. 再用 `报关单 / 完税凭证 / 清关账单 / 物流账单` 补税费、清关费、物流费。
4. 最后由系统自动生成分摊比例、综合成本、综合单价。

一句话结论：

`OA 国际物流单适合作为主入口之一，但不足以单独完成最终综合成本核算。`
