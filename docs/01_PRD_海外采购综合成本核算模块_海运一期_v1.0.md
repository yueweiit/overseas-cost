# 海外采购综合成本核算模块 PRD V1.0

## 1. 文档信息

- 文档名称：海外采购综合成本核算模块 PRD V1.0（Excel 列顺序直展示版）
- 当前阶段：一期需求定版
- 适用对象：经理、财务、产品、开发、ERP 对接同事
- 适用范围：墨西哥海运综合成本核算
- 核心数据来源：`墨西哥进口物料综合成本核算.xlsx` 中 `2026年YUEWEI` 为主

## 2. 本次定版结论

本次需求按经理最新要求调整为：

1. 前端页面不再按“关联单据 / 费用池 / 分摊规则 / SKU 明细”等多模块拆分展示。
2. 一期主页面改为“单页整表展示”模式。
3. 表格字段严格按照 Excel 原始列顺序展示，不做字段重组，不改变列顺序。
4. 当前只处理海运数据，且优先使用 `2026年YUEWEI` 中海运相关记录。
5. 空运、快递、电商场景本期不做，仅预留后续扩展入口。
6. 运费、汇率均视为动态变量，不按固定值处理。
7. 费用分摊口径需支持按费用项分别配置，不允许全表只固定一种分摊方式。

## 3. 项目背景

当前海外采购综合成本核算主要依赖财务人工维护 Excel。实际业务中，一票国际物流通常会关联多个采购单、多个供应商、多个 SKU，并涉及人民币、美元、比索等多币种费用。费用还会受到物流运输成本、采购价格、汇率、清关费用、墨西哥内陆杂费等因素影响，人工核算成本高、效率低、复核困难、修改留痕弱。

现有 ERP 已支持批次成本和 FIFO，因此本模块的一期目标不是重做 ERP，而是在 ERP 现有能力上补齐“海外采购综合成本核算”环节，形成一套可导入、可计算、可复核、可回写的海运成本核算闭环。

## 4. 一期范围

### 4.1 包含范围

1. 仅支持墨西哥海运场景。
2. 仅处理 `2026年YUEWEI` 为主的海运数据。
3. 支持按报关单号、运单号、物料维度查看整票数据。
4. 支持 Excel 列顺序整表展示。
5. 支持暂估版、实际版两类成本版本。
6. 支持人工修改，并保留修改痕迹。
7. 支持重新试算。
8. 支持后续回写 ERP 批次成本。
9. 支持费用项按货值、体积、重量等不同口径进行分摊。
10. 支持汇率快照与手工调整后重算。

### 4.2 不包含范围

1. 不处理空运、快递、电商业务。
2. 不做复杂工作台式多模块编排页面。
3. 不做本期自动税率查询平台。
4. 不做本期全量历史批次一次性补录。
5. 不做本期完整报表中心。

## 5. 核心产品设计

## 5.1 页面形态

页面采用“顶部操作区 + 中间整表区 + 底部操作记录区”的单页结构。

### 5.1.1 顶部操作区

顶部保留必要的业务操作，不再拆成多个内容模块。建议包含：

1. 批次选择或运单选择
2. 成本版本切换：暂估版 / 实际版
3. 查询条件：报关单号、运单号、物料编码、产品名称、海关进口名称、海关分类编码、大类
4. Excel 导入
5. 重新试算
6. 保存
7. 导出

### 5.1.2 中间整表区

中间主区域直接展示海运成本核算总表，字段顺序严格按 Excel 原列顺序从 `A` 到 `BE` 展示，不做拆块，不做重排。

页面中原来的：

1. 关联单据
2. 费用明细
3. SKU 成本分摊明细
4. 物料详情

统一收口为一个整表视图，通过查询、展开、筛选、编辑来完成查看和维护。

### 5.1.3 底部辅助区

底部保留轻量辅助信息：

1. 修改记录
2. 试算时间
3. 操作人
4. 版本状态

## 5.2 展示原则

1. 所有列按 Excel 顺序展示。
2. 用户看到的字段名尽量与 Excel 保持一致。
3. 可编辑字段直接在表格中编辑。
4. 计算字段默认只读，由系统试算生成。
5. 删除、修改、导入等高风险动作必须弹确认。
6. 同一票海运数据以同一套字段结构存储和渲染。
7. 运费、汇率、分摊系数变化后，系统需支持整票重新试算。
8. 不同费用项允许使用不同分摊依据，不要求全票统一。

## 7. 核算逻辑要求

## 7.1 一期计算原则

1. 计算逻辑以当前 Excel 成本总表为准。
2. 系统展示顺序按 Excel 列顺序，计算口径也必须与 Excel 现有口径一致。
3. 允许先导入原始值，再由系统补算派生字段。
4. 派生字段重新试算后要自动刷新。
5. 运费会随时间波动，不能按固定运费模板写死。
6. 汇率会变化，系统必须记录当前试算使用的汇率口径或汇率快照。
7. 分摊规则需支持至少三类基础口径：按货值、按体积、按重量。
8. 不同费用项可以绑定不同分摊规则。

## 7.2 当前已明确的派生字段逻辑

1. `T 分摊比例（货值比）`：按单行总货值占当前批次总货值比例计算。
2. `AX 中国到墨西哥运输费用分摊 RMB`：按该费用项绑定的分摊规则计算，默认可按货值比、体积比或重量比执行。
3. `AY 中国到墨西哥运输费用分摊 MXN PESOS`：按该费用项绑定的分摊规则计算，默认可按货值比、体积比或重量比执行。
4. `AZ 中国到墨西哥运输+清关+杂费 MXN PESOS`：由运输分摊、清关费用、杂费汇总形成。
5. `BA 分摊运输+物流+杂费到产品的价格 MXN PESOS`：用于形成单件分摊成本。
6. `BB 综合成本 RMB`：综合成本汇总值。
7. `BC 综合物品单价 RMB`：综合成本除以数量后的单件成本。

说明：

1. 对于 `BA`、`BB`、`BC`，默认由系统根据 Excel 口径试算生成。
2. 若财务确认需要人工修正，允许人工修改，但必须记录修改人、修改时间、修改前后值。
3. 若运费上涨、汇率变化或分摊规则切换，系统需允许基于当前版本重新试算并保留新旧结果。

## 7.3 暂估与实际

1. 系统支持暂估版、实际版两套成本版本。
2. 暂估版允许在完税凭证、最终账单未齐时先生成。
3. 后续拿到正式费用后，允许切换到实际版补差。
4. 两个版本都需要留痕，不允许直接覆盖。
5. 暂估版与实际版均需保存各自使用的运费、汇率和分摊规则快照。

## 8. 页面交互要求

1. 表头支持横向滚动查看全部字段。
2. 表格支持按报关单号、运单号、物料编码、产品名称、海关进口名称、海关分类编码、大类进行查询。
3. 查询命中后需高亮匹配字段。
4. 支持按运单或报关单筛出对应整票数据。
5. 支持点击“重新试算”刷新所有派生字段。
6. 支持直接编辑可编辑单元格。
7. 每次编辑后必须写入修改记录。
8. 删除记录、覆盖导入、重置数据等操作必须二次确认。
9. 支持 Excel 导入，导入后按当前字段结构落表。
10. 支持导出当前表格结果。
11. 支持查看或维护当前试算使用的汇率信息。
12. 支持费用项分摊依据切换后重新试算。

## 9. 数据来源与对接要求

## 9.1 本期数据来源

1. 以 `墨西哥进口物料综合成本核算.xlsx` 为主。
2. 当前阶段以 `2026年YUEWEI` 的海运记录为主。
3. 其他表单本期仅用于字段参考，不作为主展示数据源。

## 9.2 后续对接方向

1. 对接 ERP 批次成本模块。
2. 支持批次成本回写。
3. 支持 FIFO 核算消费。
4. 支持后续接入附件解析能力，包括报关单、提单、发票、完税凭证等。

## 10. 验收标准

一期验收至少满足以下条件：

1. 页面主表字段顺序与 Excel `A ~ BE` 完全一致。
2. 海运数据可正常导入并展示。
3. 查询、编辑、重新试算可用。
4. 派生字段能按既定口径自动刷新。
5. 暂估版、实际版可切换。
6. 修改痕迹可追溯。
7. 结果可导出。
8. 页面不再依赖多模块拆分逻辑，主流程以整表维护为主。

## 11. 开发建议

建议开发顺序如下：

1. 先完成主表字段结构和整表渲染。
2. 再完成导入、查询、编辑、留痕。
3. 然后补齐重新试算与版本切换。
4. 最后对接 ERP 回写与附件解析扩展。

本期的产品实现重点不是页面复杂度，而是字段口径、计算一致性和财务对账效率。
