# 数据目录说明

适用目录：`data`

这个目录用于存放后续开发过程中使用的数据样例和中间数据。

## 建议放什么

1. OA 导出样例
2. Excel 成本总表样例
3. 字段映射中间结果
4. 导入失败样例
5. 测试专用 mock 数据

## 命名建议

1. `oa-国际物流单-日期.xlsx`
2. `excel-成本总表-版本.xlsx`
3. `mapping-字段映射-v1.json`
4. `test-海运样例-批次号.json`

## 注意事项

1. 尽量不要把无关的个人临时文件扔进这里。
2. 样例数据如果包含敏感信息，建议脱敏后再保存。
3. 同类数据建议保留版本号或日期。
